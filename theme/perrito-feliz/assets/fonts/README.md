# Fuentes

Este tema usa **Inter** (body) y **Fraunces** (headings), auto-hospedadas para mejor rendimiento.

## Como instalar las fuentes (una sola vez)

1. Descarga las variantes necesarias desde [google-webfonts-helper](https://gwfh.mranftl.com/fonts):
   - **Inter**: Regular (400), Medium (500), SemiBold (600), Bold (700)
   - **Fraunces**: Regular (400), SemiBold (600), Bold (700)
2. Elige `Modern Browsers` y descarga el ZIP.
3. Pon los archivos `.woff2` en esta carpeta con estos nombres:
   - `Inter-Regular.woff2`
   - `Inter-Medium.woff2`
   - `Inter-SemiBold.woff2`
   - `Inter-Bold.woff2`
   - `Fraunces-Regular.woff2`
   - `Fraunces-SemiBold.woff2`
   - `Fraunces-Bold.woff2`

## Fallback

Si las fuentes no estan presentes, el tema cae al `font-family` del sistema (Inter / Fraunces -> system stack). El sitio se ve bien igual pero pierde el look premium de la tipografia serif.
